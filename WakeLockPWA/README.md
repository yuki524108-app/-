# WakeLock PWA

Macなし・無料で使うためのPWA版プロトタイプです。

## できること

- アラーム時刻の設定
- ON/OFF
- 曜日設定
- 解除コードの保存
- 指定時刻にページが開いている場合のアラーム音
- QRコード読み取りによる解除
- ホーム画面追加用のPWA設定
- iPhone Safari向けの `jsQR` フォールバック

## 重要な制約

- iPhone標準アラームのように、Safari/PWAが閉じていても確実に鳴らすことはできません。
- QR読み取りにはHTTPSが必要です。ローカルのHTTPやファイル直開きではカメラが動かない場合があります。
- QR読み取りのためにCDNから `jsQR` を読み込みます。オフラインでは手入力解除を使ってください。
- 無料運用では、iPhone標準アラームで起きてからこのPWAを開く使い方が現実的です。

## 無料でiPhoneから使う方法

1. このフォルダをGitHub PagesやCloudflare Pagesに無料公開します。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタンから「ホーム画面に追加」を選びます。
4. 解除コードを生成し、その文字列でQRコードを作って洗面所などに貼ります。
5. iPhone標準アラームを同じ時刻に設定し、起きたらWakeLockを開いてQR解除します。
